# 比价雷达

Android DSH 作品插件，包名 `@local/local-hnysqukwki-11kyqfw`，面板 id `local-hnysqukwki-11kyqfw`。

## 能做什么

- 支持三类比价：商品（淘宝/拼多多/抖音商城/京东）、酒店和机票（携程/美团/去哪儿）。悬浮入口自动判断当前是商品、酒店还是机票。跨 App 悬浮球的布局/动效由宿主原生层绘制，作品只能注册动作和短标签，不能修改它的样式。
- 当前详情页就是来源：商品记录标题/规格/到手价；酒店记录酒店/日期/房型/每晚价；机票记录航班号/日期/航线/舱位/票价，**不再搜索同一平台**，只查其他平台。
- 不要求复制链接、不打开分享面板、不截图、不加购物车、不下单。链接只在页面直接可见时顺便记录；看不到就留空，并明确标注“页面核验，未保存链接”。
- 每场比价只启动一个执行任务，手机操控按作品授权一次；提示词要求普通搜索、切换 App、返回、点券、滚动都不再逐项询问，只有登录/验证码/支付/风控或规格不明确时才停下。
- 只记录有正品心智的渠道：官方旗舰店、天猫国际、百亿补贴、品牌超值购、京东自营、京东国际、品牌黑标。
- 券与满减只在需要时查一次：淘宝「我的」券、拼多多百补频道左上角会员入口、抖音商城首页领券页、京东商品页领券区；满减按“刚好凑到门槛、其他凑单可取消”估算并写进假设。
- 比价表展示每个平台的首屏价格（酒店/晚、机票/人）、条件、核验时间、页面条件（`specSeen`）和一致性（`match`）；颜色/款式不同或看不清会备注，且不参与最低价，只声称「已核验来源中的最低价」。同款价格与非同款参考价在记录卡和详情里分开显示。
- 同款优先于低价：搜索结果型号/BOA/颜色/尺码不一致时先继续找同款；找不到就记 missing，不拿更便宜的不同款当平台价。
- 记录里的「复核价格」会用同一个商品标题/规格重新核对各平台，更新**同一条记录**的价格和核验时间，不新建重复记录；超过 24 小时的渠道会标记“建议复核”。
- 记下候选只要求商品名和页面价格；规格、店铺、链接、备注都在“更多”里可选，不强制填。
- 操作链路记忆按平台保存，可手动编辑，也可让 AI 根据最近一次任务优化；v2 旧记忆会自动迁移到“不复制链接、不重复搜索”的新链路。
- 相机拍商品页 → 本地 OCR → 已登录模型整理商品名/规格/价格/店铺类型；本地保存候选、比价记录和设置。
- 一边比价一边保存：读完来源页先写一次，之后每核验一个平台就更新宿主读取的固定结果文件（作品工作区 `agent-results.json`）；作品每 3 秒读取一次并写入记录，卡住或停止也不会丢掉已核验价格。
- 每次启动比价立即创建并打开一条“正在读取/等待处理”的记录；核验结果随后边写边更新同一条记录，不新建重复项。
- 比价结束自动再拉一次最新结果文件并刷新当前记录；记录详情顶部和首页「最近比价」都提供「刷新抓价」，可随时拉取最新抓价，不启动新任务（「复核价格」才启动新任务）。
- 任务在写入任何价格前失败（如无障碍断开）也会导入一条“比价未开始”记录，保留失败原因，不再静默消失。
- 若跨 App 悬浮入口开关处于关闭状态，首页「开始比价」和候选比价会直接报错并提示先打开悬浮入口，不再进入 start 页。
- 悬浮入口同时参考 actions.show() 的实际结果；宿主隐藏/拒绝入口时，首页开关会显示不可用，而不是只在 caps.overlay 缺失时放行。
- 悬浮开关同时要求共享无障碍服务已连接；a11y=false 时开关强制关闭、点击直接打开能力中心，入口 actions 隐藏；a11y 恢复后按原偏好自动开启。首页“去开启”直接打开能力中心。
- 悬浮开关还会核对系统「显示在其他应用上层」权限；系统权限关闭时开关强制显示为关闭、点击报错且勾选立即回弹、并调用 actions.hide() 收起悬浮入口；点击开启会直接打开能力中心，授权返回后自动重新检测并开启。开始比价同样拦截。
- 打开目标 App 先看当前页；如果是上次留下的别的型号，直接搜索目标款，不在错误商品页核价。
- 无障碍未连接时首页显示明确警告；能力页显示真实的 `serviceConnected` / `bridgeListening`，可点“刷新状态”。系统设置里的开关为 on 不等于桥已连上。
- 中文平台名（美团/携程/去哪儿/淘宝等）会自动映射为内部 ID，避免渠道被丢弃。悬浮比价依赖共享无障碍服务，读不到屏幕会停下并通知，不会盲点。
- 强制顺序：悬浮任务读屏后的第二个工具调用必须是 `write` 写来源；来源保存后作品会通过 `agent.steer` 催它只查其他平台，60 秒还没保存会再催一次。
- 防卡住/极速：价格只看商品首屏，默认不下滑；首屏没有价格才允许 1 次滚动；每个平台约 8 次操作预算；不为了店铺类型/规格/券进店铺、评价、详情或券中心；无可读内容（如 SKU 浮层）立即返回；不打开分享/剪贴板；不用 `open` 打商品链接；券页最多进一次；工具卡超过 3 分钟无进展会提示“可能卡住”。
- 系统级后台价格提醒、文件导出、发布到作品墙。

## 实现

- Host 半：普通 Loader 入口，无自有服务，不读凭据，不安装第二个无障碍服务。
- Client 半：`main` 面板 + `sidebar.panellist` 入口；`registerPanel` 绑定宿主「打开作品」，`ui.registerNavigation` 处理返回与设置，`ui.mountTaskControl` 复用宿主任务控件。
- 手机操控通过 `agent.start` 启动真实 DSH 执行会话，使用共享的 `mcp__phone__*` 工具；不使用 `ai.complete` 冒充手机操作。悬浮入口启动的任务在重新打开作品时通过 `agent.results()` 导入，并用结果指纹去重。
- 数据：`data.read/write('records' | 'candidates' | 'memory' | 'settings' | 'activeRun' | 'lastAgentResult')`。
- 能力：`capabilities.status/request`、`camera.capture` + `ocr.recognize` + `ai.complete`、`reminders.schedule/list/cancel`、`files.export`、`widget.update`、`publish`。
- 悬浮入口：注册 1 个 `kind: agent` 动作「立即比价」，使用系统唯一悬浮入口；平台选择与记忆更新后会重新注册提示词。跨 App 悬浮球的布局/动效由系统原生层绘制，作品不能修改。
